# Atribuciones

Este fichero se **regenera automáticamente** por el script de descarga del
catálogo de señales (`AUT-TSK-0006`, `scripts/fetch-signs.mjs`, pendiente de
implementar) a partir de los metadatos (`extmetadata`) de cada fichero de
Wikimedia Commons. No editar a mano las secciones generadas: los cambios se
perderían en la siguiente ejecución del script.

Formato de cada entrada, una vez generado:

```
- Código: R-101
  Fichero: public/signs/r101.svg
  Autor: <autor o "Ministerio del Interior / DGT">
  Licencia: <Public Domain | CC0 1.0 | CC BY-SA 4.0 | ...>
  Origen: https://commons.wikimedia.org/wiki/File:...
```
